# 🐾 Tail Tales

Turn your dog into the star of their own story.

Built for the DEV Weekend Challenge: Dog Days Edition.

## What it does
Enter your dog's name, breed, and a quirky habit, pick a genre (mystery, comedy, heartwarming, or thriller), 
and Gemini writes a short story from your dog's point of view.

## Live demo
[tail-tales-pink.vercel.app](https://tail-tales-pink.vercel.app)

## Built with
- HTML, CSS, JavaScript
- Gemini API (via Vercel serverless function)
- Deployed on Vercel
